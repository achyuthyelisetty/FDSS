# Signal-Logic-Model
AI-powered Financial Decision Support System that combines machine learning, technical indicators, and news sentiment to generate Buy, Sell, or Hold recommendations. Built using Python, Scikit-learn, XGBoost, and real-world financial market data.


AI-Powered Financial Decision Support System
Overview
This project is an AI-powered Financial Decision Support System that analyzes market data and financial news to generate Buy, Sell, or Hold recommendations.

It combines multiple machine learning models with technical indicators and a custom Signal Logic Model (SLM) to support investment decision-making.

Features
Historical market data collection
Financial news analysis
Feature engineering
Trend prediction
Market regime classification
Volatility prediction
News sentiment analysis
Buy / Sell / Hold recommendation
Tech Stack
Python
Pandas

XGBoost

Project Workflow
Collect market and news data
Perform feature engineering
Train machine learning models
Combine model predictions using the Signal Logic Model (SLM)
Generate the final Buy, Sell, or Hold recommendation
